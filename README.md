# QuickSendoff · 一键送走

给类脑答疑组用的 Vencord 插件：右键违规消息，一键完成「预约送走 + 公屏小作文」。

- 调用 **FoX | 青丘掌事** 的「预约送走」，自动填写处罚原因、私信模板、延迟时间并提交
- 送走成功后，可选地调用 **类脑娘-Gacha** 的 `/预设消息 发送`，引用那条消息在公屏发小作文
- 预设可视化编辑：每种违规情况一张卡片，菜单里一键选择

> 只是把你本来要手动点的流程自动化，权限仍由两个 bot 判断：没有对应身份组的人用不了。

## 安装

这是一个 Vencord **userplugin**，需要用源码版 Vencord 构建。

```bash
cd 你的Vencord目录/src/userplugins
git clone https://github.com/xma1Soap/vencord-quick-sendoff quickSendoff
cd ../..
pnpm build
```

然后在 Discord 里按 `Ctrl+R` 刷新，到 设置 → Vencord → 插件 里启用 **QuickSendoff**。

更新：在 `quickSendoff` 目录里 `git pull`，再 `pnpm build`、`Ctrl+R`。

## 使用

右键违规消息 → **一键送走** → 选择预设。

送走对象就是这条消息的作者。默认会先弹确认框，确认后依次执行：

1. fox 预约送走，等到「预约成功」回执
2. （开启了 gacha 且预设填了公屏小作文时）gacha 引用该消息公示小作文
3. 右下角提示结果；如果 fox 成功但公示失败，会提示你手动补发

## 设置

| 设置 | 说明 |
|---|---|
| Fox App Id / Gacha App Id | 已内置类脑服务器的两个 bot，一般不用改 |
| 启用 gacha | 送走成功后是否自动公示小作文 |
| 执行前确认 | 每次执行前弹确认框（建议保持开启） |
| 送走预设 | 可视化编辑器，见下文 |
| 抓包模式 | 排查问题用：在控制台打印 bot 的原始数据，并在菜单里显示「🧪 仅测试 gacha」 |

### 送走预设

每个预设对应菜单里的一个选项，可以新增、复制、删除、调整顺序，改动自动保存。

- **处罚原因**：自由填写，或点快捷按钮（违规第三方 / 违规云酒馆 / …）
- **延迟时间**：`1m`–`120m` 或 `1h`–`2h`，填错会标红
- **私信模板**：fox 私发的小作文，下拉选择；每次调用 fox 时会自动和 fox 的模板列表同步
- **公屏小作文**：gacha 的预设名，留空则只送走不公示

点编辑器上方的 **🔄 从 gacha 获取公屏小作文列表**，插件会调用 `/预设消息 列表` 拉取全部预设名（仅自己可见，不会发到公屏），之后输入框就能下拉选择和搜索。需要先打开类脑服务器的任意一个频道。

## 注意事项

- gacha 有**全局 15 秒冷却**（所有人共用），刚有人用过时公示会失败，等一会再补发即可
- gacha 的个人设置「发送前确认」开着时，插件会自动替你点「✅ 发送」
- 预约存在 fox 的内存里，fox 重启会丢失未执行的预约；要撤销请用 `/预约送走-取消`
- 插件通过 Discord 客户端模拟你的操作，属于客户端修改，请自行评估风险

## 测试 gacha（不发送）

打开 **抓包模式** 后，菜单里会多出「🧪 仅测试 gacha（不发送）」：只走到 gacha 的确认预览，然后自动点「❌ 取消」，用来确认预设名和权限没问题。前提是你在 gacha 里的「发送前确认」是开着的（默认开启）。

## 原理

插件不模拟点击界面，而是直接发送和 Discord 客户端相同的交互请求：

- 触发 fox 的消息右键命令 → 截住弹窗事件 → 按字段标题找到本次随机生成的 `custom_id` → 提交弹窗
- 调用 gacha 的斜杠命令 `/预设消息 发送 name message_link`，代替右键「💬 使用预设消息回复」那条长链
- 监听 bot 的回执消息判断成功或失败

依据的 bot 源码：[dz114879/fox-dayi-bot](https://github.com/dz114879/fox-dayi-bot)、[Echoer009/Odysseia-Gacha](https://github.com/Echoer009/Odysseia-Gacha)。bot 改了命令名、弹窗字段或回执格式时，插件需要跟着更新。
